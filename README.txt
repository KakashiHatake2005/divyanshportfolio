Deploy on Vercel
1) Easiest (no code): push this folder to a GitHub repo, then on vercel.com click Add New > Project, import the repo, leave all settings as default, and press Deploy.
2) Or with the CLI: install Node.js, open a terminal in this folder, run:  npx vercel  (then  npx vercel --prod)
No build step is needed. Framework preset: Other. Output directory: leave blank.
To edit links later, open index.html and change the href values.
